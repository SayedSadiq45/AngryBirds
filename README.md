📖 About the Project

Python Angry Birds is a 2D physics-based game inspired by the popular Angry Birds series. Players launch birds using a slingshot to destroy structures and eliminate pigs. The game uses realistic physics powered by Pymunk and graphics rendered with Pygame.

The project demonstrates concepts of:

Object-Oriented Programming (OOP)
Game Development
Physics Simulation
Collision Detection
JSON Data Handling
Event Handling in Python

📦 Requirements

Install the following before running the game:

Python 3.7 or later
Pygame
Pymunk 5.5.0

Install dependencies:

pip install pygame
pip install pymunk==5.5.0

or

pip install -r requirements.txt

▶️ How to Run

Clone the repository:

git clone https://github.com/yourusername/PythonAngryBirds.git

Move into the project directory:

cd PythonAngryBirds

Run the game:

python main.py
🎮 How to Play
Launch the game.
Click and hold the bird on the slingshot.
Drag the bird backwards to adjust power and direction.
Release the mouse button to launch the bird.
Destroy blocks and eliminate all pigs to complete the level.
🎯 Game Controls
Action	Control
